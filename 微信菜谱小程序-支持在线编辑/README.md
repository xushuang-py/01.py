# 灶台日记｜微信菜谱小程序

一个暖色系的家常菜谱小程序，包含：

- 首页菜谱浏览：分类筛选、关键词搜索、今日推荐
- 菜谱卡片：菜品图片、烹饪时长、难度、收藏按钮
- 详情页：食材准备清单、分步炒菜步骤、小贴士
- 收藏状态：使用微信本地缓存保存，首页和详情页同步
- 菜谱管理：小程序内直接新增或编辑菜名、分类、图片、食材和步骤
- 本地保存：自定义菜谱和修改结果保存在当前微信开发者工具/手机缓存

## 预览

1. 打开微信开发者工具，选择「导入项目」。
2. 项目目录选择当前文件夹 `2026-09-07/w`。
3. AppID 可先选择「测试号」，点击编译即可预览。

菜品图片当前使用 Unsplash 远程图片链接；项目配置已将 `urlCheck` 关闭，开发者工具模拟器可以直接预览。正式发布时建议替换为项目内 `images/` 下的本地图片，并使用你自己的 AppID。

## 目录

`app.json`：小程序全局配置  
`data/recipes.js`：内置菜谱数据，适合开发者批量维护  
`utils/recipe-store.js`：内置菜谱修改和自定义菜谱的本地存储  
`pages/index/`：首页、搜索、分类和收藏  
`pages/detail/`：菜谱详情、食材和步骤  
`pages/manage/`：菜谱管理列表  
`pages/editor/`：新增/编辑菜谱表单

## 在小程序里添加菜品

首页右上角点击「管理」，再点击「添加一道新菜」。填写菜名、分类、难度、时间，点击图片区域从相册选择或拍照；在「食材准备」和「制作步骤」区域可以点击右侧按钮继续增加输入项。点击「保存菜谱」后，首页会自动显示新菜。

已有菜谱可以在「管理」列表中点击进入编辑，也可以从菜谱详情页底部点击「编辑这道菜谱」。

这些操作不需要改代码。图片和自定义菜谱只保存在当前设备的本地缓存；如果清除小程序缓存或换设备，需要重新添加。
